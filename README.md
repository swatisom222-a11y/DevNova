# DevNova

DevNova is a modern and responsive educational platform website built using React and Tailwind CSS.  
It is designed for students, beginners, and future developers to explore industry-focused programming courses and real-world projects.

---

# Features

- Modern and clean UI design
- Fully responsive layout
- Hero section with attractive landing page
- Courses showcase section
- Student projects section
- Mentor profiles
- Achievements and testimonials
- Pricing plans section
- Mobile-friendly design
- Component-based architecture

---

# Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Vite

---

# Sections Included

- Home
- Courses
- Student Projects
- Mentors
- Testimonials
- Pricing Plans
- Footer

---

# Purpose

This project was built to practice frontend development skills and create a professional modern landing page for an ed-tech platform.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/DevNova.git
```

Navigate to project folder:

```bash
cd DevNova
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
